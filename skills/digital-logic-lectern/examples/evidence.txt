== dltool code --bits 8 --value -5 ==
8 位，真值 -5，表示范围 -128 ~ 127
原码：10000101（符号位 1，数值位 0000101）
反码：11111010（原码数值位逐位取反）
补码：11111011（反码末位加 1）
移码：01111011（真值加 2^7，即补码符号位取反）
== dltool code --bits 8 --value -128 ==
8 位，真值 -128，表示范围 -128 ~ 127
原码：100000000（符号位 1，数值位 10000000）
反码：01111111（原码数值位逐位取反）
补码：10000000（反码末位加 1）
移码：00000000（真值加 2^7，即补码符号位取反）
注意：最小负数没有对应的原码与反码表示。
