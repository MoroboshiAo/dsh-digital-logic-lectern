# 术语表

改讲稿时术语必须与教材一致。这里只收容易写错、容易混的说法。

| 术语 | 一句话界定 | 常见误写 |
| --- | --- | --- |
| 最小项 | 每个变量以原变量或反变量出现且只出现一次的与项 | 最小项不是"最小的项" |
| 最大项 | 每个变量以原变量或反变量出现且只出现一次的或项 | 与最小项互为对偶 |
| 无关项 | 输入组合不会出现或输出无所谓，记作 d 或 × | 又叫约束项、任意项，教材用词可能不同 |
| 质蕴含项 | 不能再与任何其他项合并的与项 | 不等于最简式里的项 |
| 蕴涵项 | 函数值为 1 的所有最小项都被它覆盖的与项 | — |
| 竞争 | 信号经不同路径到达同一点的时间差 | 竞争不一定产生冒险 |
| 冒险 | 竞争在输出端造成窄脉冲 | 分静态 0 型、静态 1 型、动态型 |
| 空翻 | 电平触发器件在使能期间多次翻转 | 边沿触发没有空翻 |
| 透明 | 锁存器使能期间输入直通输出 | 只对电平触发成立 |
| 次态 | 时钟沿到来之后的状态 | 不要写成"下一状态"混用 |
| 激励表 | 由现态与次态反推触发器输入的表 | 与状态表不同 |
| 状态等价 | 两个状态对所有输入序列输出相同 | 等价状态可以合并 |
| 字扩展 | 增加字数，数据线并联，高位地址选片 | 与位扩展方向相反 |
| 位扩展 | 增加字长，地址线并联，数据线拼接 | — |
| 宏单元 | CPLD 中可独立配置的逻辑块 | 与 FPGA 的 CLB 不是同一概念 |
| LUT | 查找表，本质是 2ᵏ×1 的存储单元 | 不是门电路 |
| ASM 图 | 算法状态机图，含状态框、判断框、条件输出框 | 不等于流程图 |
| 微指令 | 直接控制硬件门的控制字 | 不等于机器指令 |
| 可综合 | 能被综合工具映射成实际电路 | 与"能仿真"不是一回事 |
| 阻塞赋值 | `=`，顺序执行 | 组合逻辑使用 |
| 非阻塞赋值 | `<=`，同一时刻统一更新 | 时序逻辑使用 |
