# M8 Verilog HDL

## 一句话钩子

Verilog 不是编程，是在描述硬件怎么连、什么时候采样。

## 讲解主线（不超过 7 步）

1. `module` 声明端口，内部信号用 `wire` 与 `reg` 区分
2. `assign` 描述组合逻辑，写出来就是一根线加一个门
3. `always @(*)` 描述组合逻辑，敏感表必须写全
4. `always @(posedge clk)` 描述时序逻辑，只在时钟沿动作
5. 时序用非阻塞 `<=`，组合用阻塞 `=`，这条不能混
6. testbench：产生激励，用 `$display` 或 `$monitor` 观察
7. 组合块里漏写 `else`，综合工具会推断出锁存器

## 必讲反例

```verilog
always @(*) begin
	if (en) y = a;      // 漏了 else，y 在 en=0 时必须保持 → 推断出锁存器
end
```

正确的组合写法是给所有分支都赋值：

```verilog
always @(*) begin
	if (en) y = a;
	else y = 1'b0;
end
```

学生写第二种写法时往往只是为了"消警告"，要讲清它是语义修正，不是格式修正。

## 三个常见误解

- 以为 `always` 块按行顺序执行。它是并行描述，行序不代表硬件顺序。
- 以为 `begin/end` 里用 `=` 就是软件赋值。仿真与综合语义不一致时，出错的是这种写法。
- 以为 `initial` 能综合。一般不能，它只服务于仿真。
