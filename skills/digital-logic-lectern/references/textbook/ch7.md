# 第七章 A/D转换与D/A转换

## 7.1 数字信号处理的基本概念
### 7.1.1 模拟量与数字量的转换
- 模拟量在时间上和幅值上都连续，数字量在时间上和幅值上都离散，两者之间的转换要经过采样、量化和编码等步骤。
- D/A 转换把数字量按各位的权值转换成对应的模拟电压或电流，A/D 转换则把模拟量转换成一定位数的数字代码。
- 转换器的位数决定分辨率，位数越多能区分的模拟量越小，但转换时间和电路规模也随之增加。
- 精度与分辨率不是一回事，精度还受基准电压、电阻匹配和比较器失调等因素影响。
- 实际系统常把传感器输出的微弱信号先放大到合适的范围，再送入 A/D 转换器，转换后的数字量交给处理器运算。

![模拟信号经采样和量化变成阶梯波形](figures/sampling.svg)

### 7.1.2 数字信号处理系统的组成
- 数字信号处理系统一般由模拟输入、抗混叠滤波、A/D 转换、数字处理器、D/A 转换和模拟输出等部分组成。
- 抗混叠滤波器接在采样之前，限制输入信号的带宽，使高于折叠频率的分量被衰减，避免采样后发生混叠。
- 数字处理器按程序对采样序列作运算，其字长和运算速度决定系统的精度与实时性。
- 输出端的 D/A 转换把处理结果还原为模拟量，再经低通滤波平滑，得到连续的输出波形。
- 系统各部分的时钟与基准要协调，采样时钟的稳定度直接影响转换结果的准确性。

易错：D/A 是数字量到模拟量，A/D 是模拟量到数字量，名称顺序与信号流向一致，不要记反。

### 7.1.3 采样保持电路

- 采样保持电路在采样阶段跟踪输入，在保持阶段把采样瞬间的电压存到电容上，供转换期间使用。
- 孔径时间是从发出保持命令到开关真正断开的时间，孔径抖动是这段时间的不确定量。
- 保持期间电容会因漏电和负载电流缓慢放电，转换时间越长，保持电压下降带来的误差越大。
- 输入信号变化越快，采样保持的作用越明显；变化缓慢的信号可以直接送入转换器。
- 采样保持的精度取决于开关的电荷注入、电容的介质吸收和缓冲放大器的失调。

易错：采样保持只把电压冻结，不改善量化位数；保持电容上的电压仍会漂移，不能无限延长转换时间。

## 7.2 A/D转换
### 7.2.1 采样定理
- 采样定理指出，对最高频率为 fmax 的带限信号，采样频率不低于 fmax 的 2 倍时，可以由采样序列无失真地恢复原信号。
- 采样频率的这个下限常称为奈奎斯特速率，低于它采样会使高频分量折叠到低频，形成无法分离的混叠。
- 实际信号的频谱不会严格带限，采样前要用抗混叠滤波器把高于 fmax 的分量衰减到可接受的程度。
- 采样保持电路在采样瞬间保持输入不变，使 A/D 转换期间输入稳定，减小孔径误差。
- 采样频率高于下限时恢复更容易，滤波器的过渡带可以放宽，但数据量和后续运算量随之增加。

### 7.2.2 模数转换过程
- 模数转换一般经过采样、保持、量化和编码四个步骤，前两步把连续时间信号变成离散时间信号。
- 量化把采样值归入有限个离散电平，量化间隔越小误差越小，量化误差最大为半个量化单位。
- 编码把量化后的电平用二进制代码表示，代码位数 n 与量化级数满足 2 的 n 次方关系，位数决定分辨率。
- 量化方式有舍入和截断之分，舍入的最大误差为半个量化单位，截断的最大误差接近一个量化单位。
- 采样保持与量化编码由转换器的内部电路完成，使用者关心的是转换时间、位数和输入范围等外部指标。

### 7.2.3 A/D转换器
- 并行比较型 ADC 用 2 的 n 次方减 1 个比较器同时把输入与各基准电平比较，一次比较即得结果，速度最快但器件数目最多。
- 逐次逼近型 ADC 用 D/A 转换器和比较器逐位试探，从最高位开始确定各位，n 位需 n 个节拍，速度与位数之间取得折中。
- 双积分型 ADC 先对输入积分固定时间，再对基准电压反向积分，用计数得到数字量，抗干扰能力好但转换速度慢。
- 计数式 ADC 用计数器累加，由 D/A 转换器产生阶梯电压与输入比较，结构简单，转换时间随输入大小而变。
- 选用 ADC 时要根据信号带宽、精度要求和成本，在速度与分辨率之间作取舍。

![逐次逼近型模数转换器的组成](figures/sar.svg)

### 7.2.4 ADC的性能参数
- 分辨率指能分辨的最小输入变化，通常用位数或一个最低有效位对应的模拟量表示。
- 转换时间是从发出启动信号到输出稳定数字量所需的时间，转换速率是其倒数，两者含义不同，不能混为一谈。
- 精度描述实际转换特性与理想特性的偏差，包括偏移误差、增益误差和非线性误差等。
- 量化误差由有限位数引起，理想 ADC 的量化误差在正负半个最低有效位以内。
- 输入范围、基准电压的稳定度和温度漂移都会影响实际精度，选型时要与其他指标一并考虑。

易错：采样频率不够造成的混叠无法靠提高位数弥补，必须在采样前限制信号带宽。

![量化把连续输入折成阶梯，量化误差不超过 q 的一半](figures/quantize.svg)

### 7.2.5 双积分型 ADC

- 第一次积分把输入电压接到积分器，固定时间 T1，积分器输出与输入电压的平均值成正比。
- 第二次积分把基准电压反向接入，积分器输出回到零，所用时间 T2 与输入电压成正比。
- 用同一时钟计数 T2，计数值就是转换结果，转换关系只取决于基准电压和时钟，不依赖电阻网络的精度。
- 积分过程对工频干扰有平均作用，叠加在输入上的周期噪声会被抵消，抗干扰能力较强。
- 两次积分耗时较长，转换速度慢，适合数字电压表一类对速度要求不高、对精度要求高的场合。

易错：双积分型 ADC 的转换结果与积分时间常数无关，前提是两次积分使用同一积分器和同一时钟，更换元件后要重新校准。

## 7.3 D/A转换
### 7.3.1 权电阻DAC
- 权电阻 DAC 由基准电压、权电阻网络、模拟开关和求和放大器组成，各支路的电阻按二进制权值取值。
- 每一位对应一个开关，该位为 1 时把支路接到基准电压，为 0 时接地，支路电流与这一位的权值成正比。
- 各支路电流在求和放大器的虚地点相加，输出电压与输入数字量成正比，从而实现数字量到模拟量的转换。
- 权电阻的阻值随位数按 2 的幂变化，位数较多时最大与最小电阻相差悬殊，给集成电路的制造带来困难。
- 这种结构简单、速度较快，但电阻精度直接决定转换精度，适用于位数不多的场合。

### 7.3.2 R-2R T型DAC
- R-2R 梯形网络只用 R 和 2R 两种阻值，通过 T 型连接使各节点向右看的等效电阻恒为 R，克服了权电阻阻值范围过大的问题。
- 每一位的模拟开关把对应的 2R 支路接到基准电压或地，节点电流按二进制权值分流，各路电流之和经放大器输出。
- 由于只用两种电阻，阻值的匹配容易在集成电路中实现，便于制作位数较多的 DAC。
- 输出电压与输入数字量成正比，改变基准电压的极性即可得到双极性输出。
- 转换精度取决于电阻的匹配程度和模拟开关的导通电阻，开关上的压降会引入误差。

### 7.3.3 DAC的性能参数
- 分辨率指输入数字量的位数，也可用最低有效位对应的输出变化量表示，位数越多输出台阶越细。
- 转换时间指输入数字量变化后输出达到规定误差范围所需的时间，主要由开关和放大器的响应速度决定。
- 精度包括偏移误差、增益误差和非线性误差，偏移与增益误差可以通过外部调整减小。
- 单调性要求输入数字量增加时输出不减小，在进位处出现输出回落即属非单调，会造成闭环系统不稳定。
- 温度系数、基准电压的稳定度和负载变化都会影响实际使用效果，选型时要结合系统的精度与速度要求考虑。

易错：分辨率高不等于精度高，位数只决定台阶的粗细，电阻失配和基准漂移同样带来误差。

### 7.3.4 DAC 的最低有效位与满量程

- n 位 DAC 有 2 的 n 次方个输入码，相邻码对应的输出差称为最低有效位，记为 1 LSB。
- 基准电压为 Vref 时，1 LSB 等于 Vref 除以 2 的 n 次方，位数每增加一位，台阶减半。
- 满量程输出为 2 的 n 次方减 1 个 LSB，比基准电压少一个台阶，最后一级达不到 Vref。
- 分辨率可用位数或 LSB 表示，精度则是实际输出与理想直线的最大偏差，两者不能互相替代。
- 建立时间、压摆率和负载能力决定输出能跟随多快的码字变化，选型时要与更新速率一起考虑。

易错：把满量程当成 2 的 n 次方个 LSB 会算高一个台阶；最大输出码对应的电压是 2 的 n 次方减 1 个 LSB。
