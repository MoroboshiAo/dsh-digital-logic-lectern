# 第三章 时序逻辑

## 3.1 锁存器
### 3.1.1 锁存器的基本特性
- 锁存器是时序逻辑电路中最基本的存储单元，能在输入信号作用下改变状态，并在输入撤销后保持该状态。
- 锁存器的输出由当前输入和电路原先保存的状态共同决定，这一点与只依赖当前输入的组合电路不同。
- 锁存器一般由两个门电路交叉耦合构成正反馈回路，靠反馈维持两种稳定状态，分别表示逻辑 0 和逻辑 1。
- 锁存器属于电平敏感器件，使能信号有效期间输入的任何变化都会传到输出。
### 3.1.2 基本SR锁存器
- 基本SR锁存器由两个或非门交叉耦合而成，是最简单的双稳态存储单元。
- 用或非门构成时，S 置 1 使输出置位，R 置 1 使输出复位，S、R 均为 0 时保持原状态。
- 当 S 和 R 同时为 1 时，两个输出被强迫为同一电平，破坏了互补关系，撤销输入后的状态无法确定，因此这种组合应当禁止。
- 用与非门构成的基本SR锁存器以低电平作为有效输入，置位和复位的条件与或非门形式正好相反。
- 由于输入直接控制状态、没有同步信号，基本SR锁存器主要用于开关消抖一类的简单场合。
![与非门构成的基本 SR 锁存器及功能表](figures/latch.svg)

### 3.1.3 门控SR锁存器
- 门控SR锁存器在基本SR锁存器之前增加两个与门，使输入能否起作用受时钟信号 CP 的控制。
- 当 CP=0 时输入门被封锁，锁存器保持原状态；CP=1 时 S、R 才能通过输入门作用于内部锁存器。
- 引入门控信号后，锁存器的状态更新与系统时钟同步，多个存储单元可以协调工作。
- 在 CP=1 期间输入若多次变化，输出会跟着多次翻转，这种空翻现象使门控SR锁存器不能直接用作边沿触发的存储元件。
### 3.1.4 门控D锁存器
- 门控D锁存器由门控SR锁存器把 S 端接 D、R 端接 D 的反相得到，从结构上消除了禁止输入组合。
- 当 CP=1 时输出跟随输入 D 变化，这一状态称为透明；当 CP 回到 0 时，锁存器保持 CP 下降前一刻的 D 值。
- D 锁存器只有置 1 和置 0 两种输入情况，逻辑功能简单，常用于数据暂存和总线缓冲。
- 由于 CP 有效期间输出随 D 变化，D 锁存器仍然是电平敏感器件，在需要边沿触发的同步电路中不能直接替代触发器。
易错：锁存器是电平敏感的，CP 有效期间输出会随输入改变，不能按边沿触发的时序去使用。

## 3.2 触发器
### 3.2.1 SR触发器
- 触发器是边沿触发的存储单元，状态只在时钟脉冲的上升沿或下降沿瞬间改变。
- 边沿触发的SR触发器可由门控SR锁存器加维持阻塞结构构成，使输入只在触发沿到来时被采样。
- 其功能与SR锁存器一致：S 置位、R 复位、S=R=0 时保持，S=R=1 仍属禁止状态。
- 因为一个时钟周期内输出最多改变一次，触发器克服了锁存器在电平期间的多次翻转问题。
### 3.2.2 D触发器
- D触发器在时钟边沿把输入端 D 的值送入输出，是最常用的触发器类型。
- 其特性方程为 Q(n+1)=D，次态只由触发沿时刻的 D 决定，不存在禁止输入组合。
- D触发器可用维持阻塞结构或主从结构实现，并有上升沿触发和下降沿触发两种形式。
- 由于输入单一且逻辑关系简单，D触发器广泛用于寄存器、移位寄存器和计数器的设计。

![D、JK、T 三种触发器的符号与特性方程](figures/flipflop.svg)
### 3.2.3 JK触发器
- JK触发器利用了SR触发器中被禁止的那种输入组合，使 J=K=1 时输出翻转，功能比SR触发器更完整。
- 其特性方程为 Q(n+1)=JQ' + K'Q，J 起置位作用，K 起复位作用。
- 主从JK触发器用两级锁存结构实现边沿触发，时钟高电平期间主锁存器接收输入，时钟下降时从锁存器更新输出。
- 主从结构存在一次变化问题：CP=1 期间输入若发生多次改变，输出可能与预期不符，因此要求输入在 CP=1 期间保持稳定。
### 3.2.4 触发器的应用和时间参数
- 建立时间要求输入数据在时钟沿到来之前已经稳定保持一段时间，否则可能采到错误值。
- 保持时间要求输入数据在时钟沿之后继续稳定一段时间，防止数据过早改变而影响采样。
- 传输延迟是从时钟沿到输出达到稳定值所需的时间，它限制了触发器能够工作的最高频率。
- 最高时钟频率由建立时间、保持时间和传输延迟共同决定，是衡量触发器速度性能的重要指标。
- 触发器可用于构成分频器、脉冲同步电路和按键消抖电路等。

![D 触发器在时钟上升沿把 D 送到 Q 的时序波形](figures/timing.svg)
易错：触发器在时钟边沿采样，锁存器在电平有效期间透明，两者即使功能表相同也不能随意互换。

## 3.3 寄存器和移位寄存器
### 3.3.1 寄存器
- 寄存器由一组触发器并联组成，在同一个时钟沿下同时接收并保存多位二进制数据。
- n 位寄存器需要 n 个触发器，各触发器时钟端连在一起，数据端分别接各位输入。
- 寄存器可带三态输出以便挂接总线，也可加使能控制，在不需要更新时保持原有数据。
- 并行输入并行输出的寄存器常用于暂存运算的中间结果和电路的状态信息。
### 3.3.2 移位寄存器
- 移位寄存器在时钟作用下把各位数据依次传给相邻触发器，实现数据的串行与并行转换。
- 按数据流动方向可分为左移、右移和双向移位，双向移位的方向由控制信号选择。
- 串入并出用于把串行数据转换为并行数据，并入串出用于把并行数据逐位串行发送。
- 移位寄存器还可构成环形计数器和扭环形计数器，也用于数据的延迟和序列的产生。
易错：寄存器是各位同时写入，移位寄存器是逐位传递，二者的数据更新方式不同，不能混为一谈。

## 3.4 计数器
### 3.4.1 同步计数器
- 同步计数器中所有触发器的时钟端并联，由同一个时钟沿同时触发，各触发器几乎同时更新状态。
- 由于不存在逐级延迟的累积，同步计数器工作速度快，可以达到较高的计数频率。
- 各触发器的输入由组合逻辑根据当前状态产生，进位链的设计决定了计数规律。
- 通过反馈清零或预置数改变计数长度，同步计数器可以实现任意模值的计数。
### 3.4.2 异步计数器
- 异步计数器中低位触发器的输出作为高位触发器的时钟，各级依次翻转，形成行波式进位。
- 电路结构简单、所用器件少，但各级翻转时间逐级累加，总延迟随位数增加而增大。
- 级间延迟会使状态译码时出现毛刺，因此异步计数器不宜用于高速或要求严格同步的场合。
- 异步计数器多用于速度要求不高的分频和计数电路。
### 3.4.3 中规模集成计数器及应用
- 74LS161 是四位同步二进制计数器，具有异步清零、同步置数、保持和计数四种工作方式。
- 利用 74LS161 的同步置数端可以在计到预定值时装入初值，从而构成模值小于 16 的计数器。
- 多片 74LS161 级联可扩展计数位数，低位的进位输出接到高位的使能端，实现同步级联。
- 中规模计数器常与译码器配合，构成时序脉冲分配器和分频电路。
易错：74LS161 的清零是异步的、置数是同步的，两者的作用时刻不同，设计时要分别对待。

## 3.5 定时脉冲产生器
### 3.5.1 时钟脉冲源电路
- 时钟脉冲源为时序电路提供周期稳定的方波，常用石英晶体振荡器或门电路构成的多谐振荡器实现。
- 石英晶体振荡器的频率稳定度高，适合作系统的主时钟，振荡电路可由反相器加晶体构成。
- 用门电路加 RC 构成的多谐振荡器成本低，但振荡频率受温度和电源电压的影响较大。
- 时钟源输出经过整形和分频，可以得到系统需要的各种频率的时钟信号。
### 3.5.2 节拍脉冲产生器
- 节拍脉冲产生器把主时钟变换成时间上依次错开的一组脉冲，用来控制机器各步操作的先后顺序。
- 常用计数器加译码器实现，计数器状态经译码后依次输出各拍脉冲。
- 节拍脉冲的宽度通常为一个时钟周期，各拍在时间上依次出现而不重叠。
- 为保证各拍严格有序，节拍产生器必须由同一时钟同步驱动。
### 3.5.3 数字钟
- 数字钟由石英晶体振荡器产生标准频率，经多级分频得到秒脉冲，再逐级计数得到分和时。
- 秒计数器和分计数器是模 60 计数器，时计数器为模 24 或模 12 计数器，计满后向高位进位并自身回零。
- 各级计数结果经译码器驱动七段显示器，把二进制编码转换成可读的数字。
- 数字钟通常还设有校时电路，通过置数或复位调整时间。
易错：秒和分的计数器是模 60，计到 59 之后的下一个脉冲回到 00 并向高位进位，不要把模值当成 59。

## 3.6 同步时序逻辑分析
### 3.6.1 同步时序逻辑电路的描述工具
- 状态表以表格形式列出每种现态和输入组合下的次态与输出，完整描述电路的外部行为。
- 状态图用圆圈表示状态、用带箭头的线表示转移，箭头旁标注输入和输出，直观反映状态之间的转换关系。
- 状态方程和输出方程用逻辑表达式给出次态、输出与现态及输入的关系，便于代数运算和设计。
- 这三种工具描述的是同一个电路，可以相互转换，分析时按需要选用其中一种。

![三状态时序机的状态转换图，使能有效时按 S0、S1、S2 循环](figures/state.svg)
### 3.6.2 同步时序逻辑电路分析的一般方法
- 首先由逻辑图写出各触发器的激励方程和电路的输出方程。
- 把激励方程代入所用触发器的特性方程，得到各触发器的次态方程。
- 由次态方程和输出方程列出状态表，再据此画出状态图。
- 根据状态图归纳电路的逻辑功能，检查是否存在无效状态以及电路能否自启动。
- 列状态表时按现态逐个代入，得到全部次态后再归纳规律，可以避免遗漏状态。
易错：激励方程描述的是触发器输入端的表达式，次态方程才是状态转移的结果，两者不能混用。

## 3.7 同步时序逻辑设计
### 3.7.1 同步时序逻辑设计方法和步骤
- 首先根据设计要求确定输入、输出变量，建立原始状态图或原始状态表。
- 对原始状态表进行状态化简，合并等价状态，以减少所需触发器的数目。
- 进行状态编码，为每个状态分配二进制代码，并选定触发器类型。
- 由编码后的状态表求出激励方程和输出方程，画出逻辑图，最后检查电路能否自启动。

![三状态时序电路的状态转移图](figures/state-diagram.svg)

### 3.7.2 建立原始状态表的方法
- 从文字描述中找出电路的输入序列、输出序列以及必须加以区分的状态，逐个确定状态转移。
- 每遇到一种新的状态条件就增设一个状态，先保证描述完整，不急于压缩状态数目。
- 由每个现态出发，针对每一种可能的输入确定次态和输出，逐项填入状态表。
- 原始状态表中允许存在等价状态，把它们留到状态化简步骤统一处理。
### 3.7.3 状态编码
- 状态编码是用一组二进制代码表示每个状态，代码位数 n 应满足 2^n 不小于状态总数。
- 常用的编码方式有自然二进制编码、格雷码编码和独热码编码。
- 不同的编码方案会使激励方程和输出方程的复杂程度不同，也影响电路的自启动特性。
- 编码时尽量使相邻状态的代码只相差一位，以减小状态转换过程中出现竞争的可能。
易错：状态化简必须在状态编码之前完成，编码后再合并状态会破坏已经分配的代码。
