# M4 时序逻辑

## 一句话钩子

时序逻辑的记忆不在门里，在反馈环里。

## 板书主线（不超过 7 步）

1. 锁存器：电平触发，使能期间输入直通输出，叫"透明"
2. 触发器：边沿触发，只在跳变沿采样一次
3. 空翻：电平触发期间输入变了，输出跟着翻多次
4. 主从结构把采样和输出错开，JK 触发器因此能消除空翻
5. 状态表 → 状态图 → 激励表，三步把文字需求变成方程
6. 同步设计五步：画状态图、状态编码、求激励方程、求输出方程、画电路
7. Mealy 的输出随输入变，Moore 的输出只随状态变

## 必讲反例

RS 锁存器 R=S=1 时输出不是"都置 1"，而是不确定，撤掉输入后可能停在任意一侧。这是禁用组合，不是置位。

## 三个常见误解

- 以为触发器就是锁存器。区别在触发方式：电平与边沿。
- 以为异步计数器可以随便级联成任意模。要得到非 2ⁿ 的模，必须加重置或置数逻辑。
- 以为状态编码位数越少越好。还要考虑译码复杂度、冒险和可读性。
