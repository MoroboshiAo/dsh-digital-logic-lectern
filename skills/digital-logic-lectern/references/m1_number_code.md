# M1 数制与编码

## 一句话钩子

计算机只会加，不会减。减法是被补码"骗"过去的。

## 讲解主线（不超过 7 步）

1. 权展开：`(259)₁₀ = 2×10² + 5×10¹ + 9×10⁰`
2. 除基取余，余数**逆序**读
3. 8 位字长的模是 256
4. 反码：符号位不动，数值位逐位取反
5. 补码：反码末位加一
6. `3 − 5 = 3 + 251 = 254`，超出的进位丢弃，读作 −2
7. 格雷码：相邻两个码只差一位，且是无权码

## 必讲反例

−128 没有原码，也没有反码。8 位补码能表示 −128，是因为补码的模运算天然多容纳一个负数，不是因为"反码加一"这个说法处处成立。

## 三个常见误解

- 以为补码就是反码。差一个末位加一，讲的时候要当场加给对方看。
- 以为格雷码也是有权码。它没有位权，只能按相邻性理解。
- 以为 BCD 就是二进制。8421 码里 1010 到 1111 是非法码，只能出现在运算修正前的中间结果。
